# originaldz — متجر الدفع عند الاستلام (الجزائر)

متجر إلكتروني مبني بـ **Next.js 14** + **Supabase** (مجاني)، بثلاث لغات (عربي/إنجليزي/فرنسي)،
مع نموذج طلب دفع-عند-الاستلام وتوصيل **World Express** (ولاية → مكاتب أو بلدية + عنوان)،
ولوحة إدارة كاملة.

## الميزات المطبّقة
1. زر "اطلب الآن" وزر واتساب.
2. عداد مخزون ("باقي N قطع").
3. تقييمات الزبائن.
4. أسئلة شائعة + سياسة الإرجاع/الخصوصية.
5. نافذة خصم ترحيبي مقابل رقم الهاتف.
6. تحقق من رقم الهاتف الجزائري (05/06/07).
7. قائمة سوداء (حظر أرقام).
8. علامة "عميل موثوق/خطر" حسب سجل الهاتف.
9. إشعار فوري بكل طلب عبر **Telegram**.
10. لوحة طلبيات (حالات + رقم تتبع يدوي).
12. إدارة المنتجات + المخزون.
14. بيكسل فيسبوك/تيكتوك + تتبع مصدر الطلب (UTM).
16. حزم/خصم الكمية (اشترِ N بخصم %).
17. زر مشاركة المنتج.
18. تحسين SEO (metadata + canonical).
19. صفحات "من نحن" و"سياسة الخصوصية".
20. خصم الولاء للزبون العائد.

## التشغيل محليًا

1) ثبّت التبعيات:
```bash
npm install
```

2) أنشئ ملف `.env` من `.env.example` واملأ:
```
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_ANON_KEY=
SUPABASE_SERVICE_ROLE_KEY=
ADMIN_PASSWORD=كلمة-سر-قوية
TELEGRAM_BOT_TOKEN=        # اختياري
TELEGRAM_CHAT_ID=          # اختياري
```

3) شغّل:
```bash
npm run dev
```

## الإعداد على Supabase (مجاني)

1. أنشئ مشروعًا في [supabase.com](https://supabase.com).
2. من **SQL Editor** نفّذ محتوى `supabase/schema.sql` ثم `supabase/seed.sql`.
3. انسخ `URL` و`anon key` و`service_role key` من **Project Settings → API** إلى `.env`.

## النشر على Vercel (مجاني)

1. ارفع المشروع إلى مستودع GitHub.
2. في [vercel.com](https://vercel.com) اختر **New Project** واربط المستودع.
3. أضف متغيرات البيئة نفسها (من `.env`).
4. انشر، ثم اربط الدومين `originaldz.online` من **Settings → Domains**.
5. في لوحة الإدارة `/admin` أضف منتجاتك ومكاتب World Express.

> **تلميح**: أدخل من `/admin` بكلمة السر `ADMIN_PASSWORD` التي وضعتها في البيئة.

## ملاحظات مهمة
- قائمة مكاتب World Express في `supabase/seed.sql` هي **نقطة بداية** — أكملها وعدّلها من لوحة الإدارة (المكاتب → إضافة مكتب). الشركة تحدّث مكاتبها باستمرار.
- بيانات الولايات (58) والبلديات (1541) من مشروع [dzship](https://github.com/dzbuild-com/dzship) (CC0/ملكية عامة).
- التوصيل **مشمول في سعر المنتج** (الزبون يدفع سعرًا واحدًا). يمكن لاحقًا إضافة تسعير لكل ولاية.
